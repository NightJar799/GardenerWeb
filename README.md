# pet-проект GardenerWeb

Pet - проект в котором реализован сайт садовников, в котором можно сохранять понравившееся растения искать новые растения для посадки согласно введённым условиям и предподчтеням.

## Таблица технологий

| Технология | Библиотека/фреймворк |
|---------|-----------------|
| REST API | Spring Web + Jackson |
| ORM Базы данных | Spring Data JPA + Hibernate |
| Кэширование | Spring Cache + Redis |
| Безопасность | Spring Security |
| Views | Thymeleaf |
| Валидация | Hibernate Validator |
| База данных | PostgreSQL |
| Сокращение кода | Lombok |

## База данных

База данных предварительно поднята в Docker, порт выбираеться в `application.properties`
